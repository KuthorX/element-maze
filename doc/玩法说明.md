# [draft] 元素迷宫 Element Maze

# 通关目标 Pass Level Goal

通关目标：使足够多的 `元素球 ColorBall` 抵达`白墙 WhiteWall`。

# 静态对象 Static Objects

每个方块默认为黑色背景。

1. `黑墙` `BlackWall`：吸收元素球，但不会增加分数。
2. `元素源` `ElementSource`：发射 `ColorBall` 元素球。 
3. `弹跳面` `BounceFlat`：可以让球损失一定动量的情况下，按照入射角度和出射角度弹开。
4. `白墙` `WhiteWall`：吸收元素球，会增加分数。
5. `传送门` `PortalDoors`：同组（只有 2 个）的传送门相互连接。`ColorBall` 进入其中一个 `PortalDoor` 后，会从 另一个 `PortalDoor` 发射出去。经过一组 `PortalDoors` 的 `ColorBall` 会损失一定的动量。

# 运动对象 Dynamic Objects

## 颜色球 ColorBall

默认为白色。

ColorBall 从 ElementSource 被发射出去的时候，天然带有一定的动量。

在运动和碰到 BounceFlat 、 PortalDoors 的时候，会损失一定的动量。

当动量损失为 0 时，如果还没有与 WhiteWall 发生碰撞，则会回到 ElementSource 。

当 ColorBall 碰到 WhiteWall 的时候，通过关卡。

# 玩家可互动对象 Interactable Objects

## ElementSource

玩家按住空格即可让 ElementSource 发射 ColorBall 。

当 ElementSource 发射 Element 的时候，玩家不能操作地图上的其他元素，直到 Element 失去动量。

## BounceFlat

BounceFlat 可以在一定范围内旋转，玩家可以用鼠标拖动的方式调整角度（顺时针或者逆时针，取决于鼠标方向）。

其他对象玩家无法控制。

# Maze 配置文件

- 可配置 Maze 大小（ height / width ）。
- 可配置 Maze 整体颜色。
- 可使用 二维数组 配置 Static Objects 的位置。

数据结构参考 `element_maze_levels.rpy` 。

# 通关反馈

当 `ColorBall` 与 `WhiteWall` 发生碰撞时。

1. 播放 `快门 shutter` 声。
2. 画面轻微闪烁。
